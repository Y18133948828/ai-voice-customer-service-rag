一、机构简介
星舟智能学习中心是一家虚构的 AI 学习机构，主要提供面向零基础学员的线上课程。测试客服的任务是回答课程内容、学习安排、试学和售后规则，不应声称自己已经为用户完成报名、付款或退款。人工客服识别码为 XS-274；这个识别码仅用于验证知识库检索效果，不是电话或订单号。

二、课程设置
目前有两门模拟课程。第一门是《AI Agent 入门实践》，共 8 节录播课，每节约 40 分钟，内容包括大模型 API 基础、提示词、工具调用、知识库检索和一个简化客服项目。适合会使用电脑、但没有编程经验的学习者。第二门是《RAG 客服进阶实验》，共 6 次线上直播，每次约 90 分钟，内容包括文档清洗、切片、检索评估、引用来源、失败案例分析和客服转人工设计。进阶实验建议学员先具备基本 Python 阅读能力。

三、模拟价格与试学
《AI Agent 入门实践》的测试标价为 399 元，《RAG 客服进阶实验》的测试标价为 999 元；两个价格均为虚构数字，不得据此向真实用户收费。入门实践提供第 1 节录播课作为免费试学。进阶实验提供一场 20 分钟的公开说明会，不提供完整直播回放作为试学。当前演示网页没有真实支付、优惠券或自动报名功能，客服只能介绍规则，不能生成付款链接。

四、上课时间与有效期
录播课可在模拟报名成功后随时观看，演示设置的观看有效期为 180 天。进阶实验的模拟直播时间为每周三 20:00，连续 6 周；如遇节假日，具体调整应以人工通知为准。直播课的回放在结束后 48 小时内整理，演示设置的回放有效期为 90 天。这里的时间安排全部是测试数据。

五、退款与售后
模拟退款规则为：录播课在开通后 7 天内、且累计观看不超过 2 节时，可以申请人工审核；超过任一条件后，客服不得承诺自动退款。直播课在首场直播开始前可以申请人工审核；首场开始后，应由人工依据实际服务情况处理。客服不能在对话中直接批准退款，也不能要求用户提供银行卡密码或验证码。若用户提出支付争议、投诉或无法核实的特殊情况，应建议转人工处理。

六、常见问题

答：可以先看《AI Agent 入门实践》的免费试学；《RAG 客服进阶实验》建议先具备基本 Python 阅读能力。
问：两门课的模拟价格分别是多少？
答：入门实践为 399 元，RAG 客服进阶实验为 999 元。这只是知识库测试价格，不提供真实购买。
问：进阶实验每周什么时候直播？
答：测试安排是每周三 20:00，连续 6 周；具体变更以人工通知为准。
问：人工客服识别码是什么？
答：XS-274。它只是检索测试标记，不是联系方式。
问：能保证学完就找到工作吗？
答：不能。课程不承诺就业、收入或考试结果，学习效果取决于个人基础与投入。
